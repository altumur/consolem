# Запрос от команды mockup: пульты CCTV и назначение кнопок

2026-11-16 · коммит контракта `deb9d7d` (0.13.0) · от команды mockup, для владельца контракта

Кому: владелец контракта

**Статус: новый**

## Что мы делаем

Пользователь утвердил вид настройки пультов CCTV. Это прототип 73: `index_73_pulty-cctv.html`, на Pages — https://ndm234234.github.io/consolem/index_73_pulty-cctv.html#opt=keys. В «Опциях» → «Рабочее место» появилась страница «Пульты и клавиши»:

- список пультов в двух группах: «К этому компьютеру» (клавиатура и пульты USB) и «К серверу, драйвером Axxon One»;
- окно «Подключить пульт»: способ подключения, модель из списка Axxon One, для сервера — сервер и порт;
- выбор модели вручную: Axxon One видит Dahua NKB1000 как Hikvision DS-1005KI;
- назначение кнопок по функциям «Общие», «Живое видео», «Архив», «Тревоги»: нажать кнопку или выбрать её из списка;
- правила Axxon One: кнопку из «Общих» нельзя назначить в другой функции; в одной функции одна кнопка — одно действие; букву и цифру на клавиатуре — только с Ctrl, Alt или Shift;
- сброс одного действия и всего пульта к умолчаниям, проверка нажатия на картинке пульта, отключение пульта.

Это закрывает часть пробела A17 в отчёте `docs/axxon-one-gaps.html`. В контракте пультов нет. В прототипе всё сделано заглушкой: пульты, назначения и нажатия живут в памяти страницы, нажатие кнопки — щелчок по картинке пульта.

## Источники

- Axxon One 3.0, документы Lexiro: 282589 (пульты: два способа подключения, список моделей), 282594 (Dahua NKB1000 видна как DS-1005KI), 282595 (CH VM-Desktop: кнопки не переназначаются), 590805 (горячие клавиши: функции, правила, действия и клавиши по умолчанию), 292040 (UNIVIEW KB-1100 через мастер поиска IP-устройств).
- Отчёт исследования: https://claude.ai/artifact/KNVmQ8icpV7Cbh3m6AHmAQ

## Что нужно

Имена полей и путей — наше предложение. Владелец контракта может выбрать другие.

1. **Справочник действий и моделей.** Список действий по функциям (`global`, `live`, `archive`, `alarms`) с клавишей по умолчанию и признаком «не меняется»; список моделей пультов: имя, способы подключения (`hid`, `driver`), набор кнопок, признак «кнопки не переназначаются». Например, `GET /input-devices/catalog` или раздел в `GET /kinds`.
   - Зачем: сейчас список действий, моделей и кнопок записан в странице. Сервер и клиент Axxon One должны давать один список.
   - Что сломается: ничего, путь новый.
2. **Пульт на сервере (драйвер Axxon One).** Вид объекта, например `input.keyboard`, дочерний к серверу: `model`, `port` (`USB`, `COM1`…), `enabled`, состояние связи в `status.link`.
   - Зачем: пульт через драйвер добавляют к серверу, как IP-устройство (Lexiro 282589, 292040). Сейчас консоль держит его только в странице и не показывает в «Оборудовании».
   - Что сломается: ничего, вид новый. Клиент пропускает незнакомые виды.
3. **Назначения кнопок.** Набор `{действие: кнопка}` для пульта и для клавиатуры. Нужно решение владельца: где они живут и кому действуют — рабочему месту, пользователю или пульту. В Axxon One клиент хранит их у пользователя Windows на компьютере (Lexiro 590805). Предлагаем: у пульта на сервере (п. 2) — свойство `bindings`; для пульта USB и клавиатуры — настройка пользователя, например `GET/PUT /me/input-bindings/{device}`.
   - Зачем: сейчас назначения пропадают при перезагрузке страницы.
4. **Проверки сервера.** Отказ 422 с `field` на кнопке, если кнопка из `global` назначена в другой функции, если одна кнопка у двух действий одной функции, если у модели кнопки не переназначаются.
   - Зачем: консоль держит эти правила, но сервер должен держать их и без консоли.
5. **Пульты USB рабочего места (по желанию).** Список пультов, которые видит клиент Axxon One на компьютере оператора, и последнее нажатие для проверки. Например, поток событий `input.press` с `device` и `button`.
   - Зачем: браузер администратора не видит пульт оператора. Без этого консоль показывает проверку нажатия только на картинке. Нужно решение: путь или отказ.

## Что не нужно

- Чувствительность джойстика уже есть в опциях домена («Управление PTZ» → «Чувствительность джойстика»), новое поле не нужно.

## Что делает прототип до ответа

Прототип 73 работает на заглушке. Пункт A17 в `docs/axxon-one-gaps.html` ссылается на этот запрос. Когда контракт получит пункты 1–4, консоль переведёт страницу на них и покажет пульт на сервере в «Оборудовании».
