## 3. 39 сбоев `NO_ROUTE`

Стенда с новым сгенерированным backend VMS для вашего прогона сейчас нет.
Адрес для `tests/api.html?api=<стенд>` или `tools/check_stand.py` дать не можем.
V/11 пока задаёт нормы и проект стенда; это не работающий API 0.34.0.
Поэтому прогон не выполнен, имён тестов со строкой о недостающем `needs`
у нас нет. Это отсутствие результата, а не сообщение, что таких тестов нет.

После генерации и согласованного перехода проверим механизм, затем каждый
объявленный профиль, затем видео при наличии соответствующих операций.
Сдадим строки `LAYER`, причины `SKIP` и точные имена тестов, вызвавших
необъявленную операцию без `needs`. Пропуск необъявленного профиля или видео
не будем считать провалом; пропуск обязательного для объявленного договора
поведения не будем считать доказательством готовности.
