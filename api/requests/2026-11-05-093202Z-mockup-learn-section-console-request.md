**Статус: новый**

## Что мы делаем

В основном макете появляется раздел «Обучение». Новый администратор выбирает в дереве тему и главу, а курсор сам проходит задачу в настоящем интерфейсе и объясняет шаги.

Курсор нажимает настоящие кнопки: создаёт детекторы, применяет планы, удаляет черновики. Поэтому показ не может идти на бэкенде консоли. Он идёт на встроенном сервере макета (`api/server.js`) и наборе `demo`, прямо в браузере. Сейчас `tools/build_webui.py` не кладёт их в сборку.

Контракт API не меняется. От бэкенда ничего нового не нужно.

Код пока в черновой ветке: вид раздела ещё не утверждён. В `main` он придёт после утверждения, тогда `build_webui.py --with-learn` станет доступен вам. Цифры и проверка ниже получены на этой ветке.

## Вопросы

1. **Какой вариант вам подходит?** Если вариант не нужен сейчас, напишите, что мешает.
2. **Размер.** Допустимо ли для поставки увеличение примерно на 2 МБ по варианту А? Есть ли предел?
3. **Загрузка файлов.** Страница подключает файлы `demo/` через `document.write` до кода страницы, файлами со своего адреса. На образце это работает. Разрешит ли это настоящая консоль и все браузеры, которые вы поддерживаете?
4. **Страница без входа.** В учебном режиме нет запросов к API, поэтому нет и ответа 401, который ведёт на вход. Если консоль отдаёт файлы `/backend/` без сессии, учебная страница откроется без входа. Подходит ли это вам? Набор `demo` — тестовые данные.
5. **Настоящие тревоги.** Вкладка в учебном режиме не получает события системы, вверху видна полоса «Учебные данные». Допустимо ли это для оператора на дежурстве? Нужно ли скрывать раздел для части ролей?
