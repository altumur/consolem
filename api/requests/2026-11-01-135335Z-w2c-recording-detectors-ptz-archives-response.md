## П. 6. PTZ — сделано, `8682dd2`

`Device.ptz`, `Device.presets` только чтение, вида `ptz` в фильтрах нет. В правиле номер пресета выбирается из списка, если он есть. `PUT`, `DELETE /devices/{id}/presets/{n}`. ADR-0112 доп. (2): `PUT` без `name` запоминает положение, с `name` задаёт только имя, камера не движется. Поправлено по доп. (4): `Device.presets` — все сохранённые номера, без подписи имя пустое, форма показывает номер. `PUT {}` создаёт запись с пустым именем, `PUT {name}`, пустое тоже, положения не трогает, связь и `ptz` его не судят, пустое снимает подпись, запись снимает только `DELETE`. Предел — `Device.presetMax`, номер выше предела — `404` у `PUT` и `DELETE`. Форма берёт первый свободный номер, занятые без подписи считаются. Аренда `PUT`, `DELETE /devices/{id}/ptz`: клиент продлевает каждые 1,5 с со сроком 3 с, на отпускание шлёт `DELETE`. Двое на одной камере — действует последняя сменившаяся аренда, как в нормах (V/01.4 Н1.4г). Всё это — на вкладке «Видео» для задания пресетов; движение в работе — часть просмотра.

## П. 1. `replica`: источник — сделано, `2e77c07`

`Device.replicaFrom`, `ExtraArchive.replicaFrom`: `null` — встроенное хранилище, иначе `archiveId` другого архива этой камеры. Форма разрешает режим, если у камеры есть встроенное хранилище или другой архив. В строке дополнительного архива `replica` значит то, что вы поняли: архив строки забирает из `replicaFrom`. Со встроенного — только основной поток, `sub` — `422 NOT_SUPPORTED`, `field: stream`, форма его не предлагает. Цикл и забор у самого себя — `422 VALIDATION_FAILED`, `field: replicaFrom`, цикл форма не предлагает. Источник сняли — запись ждёт, `recordState: waiting`, в строке причина, забранное живёт своим сроком.

Камера без потребителя: `online` — соединение держателя с устройством (`running`, `idle`, `held`), состояние, а не проба: простаивающая камера без потока не опрашивается. `silent` — обрыв открытого потока, а не потеря связи с устройством: у камеры без потока `silent` нет. Прежняя запись здесь была неверной, поправлено по ADR-0112 доп. (5). Живое видео по запросу с задержкой на первый кадр форма выдерживает.
