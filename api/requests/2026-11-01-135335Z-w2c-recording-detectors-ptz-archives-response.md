## П. 15. Одиночные правки и откат по стопке — сделано, `5cb5d27`; строго по стопке — `32142c5`

`POST`, `PATCH`, `DELETE /devices`, `/devices/update`, `/objects/delete` — операция: `Operation` с `single: true`, `state: done`. Список — `GET /operations`, новые сверху. Показ — «Журнал» → «Операции», одиночные вместе с групповыми, кнопка «Отменить» только у последней операции, предыдущая становится доступной после её отмены: иначе `409 NOT_REVERTIBLE`, `params.reason: notLast`. Откат идёт строго назад, поэтому предложенное в запросе «откатывать можно любую» не принято. Шаг откатывается по значениям своих полей, 50 последних, 7 суток.

Сверх запроса: «Повторить» после отмены, `POST /operations/{id}/redo`. Запись — в [файле сделанного сверх запросов](w2c-sverh-zaprosov.md).

## П. 6. PTZ — сделано, `8682dd2`

`Device.ptz`, `Device.presets` только чтение, вида `ptz` в фильтрах нет. В правиле номер пресета выбирается из списка, если он есть. `PUT`, `DELETE /devices/{id}/presets/{n}`. ADR-0112 доп. (2): `PUT` без `name` запоминает положение, с `name` задаёт только имя, камера не движется. `Device.presets` — только названные, предел — `Device.presetMax`, номер выше предела — `404` у `PUT` и `DELETE`. Форма берёт первый свободный номер, безымянные ведёт номером. Аренда `PUT`, `DELETE /devices/{id}/ptz`: клиент продлевает каждые 1,5 с со сроком 3 с, на отпускание шлёт `DELETE`. Двое на одной камере — действует последняя сменившаяся аренда, как в нормах (V/01.4 Н1.4г). Всё это — на вкладке «Видео» для задания пресетов; движение в работе — часть просмотра.

## П. 1. `replica`: источник — сделано, `2e77c07`

`Device.replicaFrom`, `ExtraArchive.replicaFrom`: `null` — встроенное хранилище, иначе `archiveId` другого архива этой камеры. Форма разрешает режим, если у камеры есть встроенное хранилище или другой архив. В строке дополнительного архива `replica` значит то, что вы поняли: архив строки забирает из `replicaFrom`. Со встроенного — только основной поток, `sub` — `422 NOT_SUPPORTED`, `field: stream`, форма его не предлагает. Цикл и забор у самого себя — `422 VALIDATION_FAILED`, `field: replicaFrom`, цикл форма не предлагает. Источник сняли — запись ждёт, `recordState: waiting`, в строке причина, забранное живёт своим сроком.

Камера без потребителя: `online` значит «устройство отвечает», а не «идёт видео». `silent` судит то же: пропала связь с устройством. Живое видео по запросу с задержкой на первый кадр форма выдерживает.

Выбор архива у камеры учитывает `recordModes`.
