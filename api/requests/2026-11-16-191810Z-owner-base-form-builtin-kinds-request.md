# Запрос от владельца контракта: базовая форма у встроенных видов

2026-11-16 · коммит контракта `c0d1c46` · от владельца контракта (joynickray), для mockup

Кому: mockup

**Статус: в работе**

## Зачем

У объекта две формы:
- **базовая** — форма по схеме вида (`schemaFormHtml`). Её строит интерфейс, код под вид не нужен;
- **своя** — экран под вид: у плагина psim это его страница (`setupUi`), у встроенного вида — ручной экран консоли, привязанный к профилю (`vms.camera/1`, `vms.pos/1`…).

Своя форма может быть, а может не быть. Базовая форма должна быть у каждого объекта.

Сейчас это так только у видов плагинов. У встроенного вида (камера, касса, сервер, хранилище…) ручной экран заменяет базовую форму. Форма по схеме видна только на вкладке «Дополнительно» и только для свойств сверх профиля. Кроме того, ручной экран выбирается по `n.type` (`tabsForHand`), а README говорит, что по профилю.

## Что нужно

1. **Базовая форма у каждого объекта.** У объекта со своим экраном базовая форма тоже открывается: например, переключателем «Своя форма / Все свойства» или вкладкой. В базовой форме — все свойства из схемы вида, с проверками сервера, как у незнакомого вида.
2. **Ручной экран — по профилю.** Интерфейс выбирает экран по `implements` вида, а не по коду вида. Вид плагина, который объявил профиль, получает тот же экран.
3. **Без экрана — базовая форма.** Вид, у которого нет ни ручного экрана, ни `setupUi`, открывается базовой формой. Так уже сделано, проверить, что ничего не выпало.

Как сделать (переключатель, вкладка или иначе) — решает mockup, сначала в прототипе.

## Что сломается

Контракт не меняется. Это правка интерфейса.
