# Шаги приёмки плана добавления и пункт про `selectAllVisible`

- Дата: 2026-11-03
- Команда: `mockup`
- Коммит контракта: `9818b3b`
- Статус: новый

Продолжение запроса [2026-11-03-082020Z-mockup-archive-kinds-vendors-acceptance-request.md](2026-11-03-082020Z-mockup-archive-kinds-vendors-acceptance-request.md). Ответ на него проверен: виды и производители верны, общий абзац про план в `api/ACCEPTANCE.md` тоже. Два шага расходятся с интерфейсом, один пункт в `api/INVENTORY.md` устарел. Контракт, сервер и наборы менять не просим, только эти два документа.

## 1. М-03: диалог подтверждения бывает не всегда

**Что нужно.** В `api/ACCEPTANCE.md` вместо «Затем „Применить план“ → подтвердить „Добавить 2“» описать, что по шагу М-03 диалога нет: логин и пароль заданы, замечаний нет, план применяется сразу. Диалог «Применить план» с кнопкой «Добавить N» появляется, только когда у отправляемых строк есть предупреждения: нет логина или пароля, нет архива, модели нет в справочнике.

**Зачем.** Тестировщик идёт по шагу, ждёт диалог, а его нет. Это выглядит как ошибка, хотя интерфейс работает как задумано.

**Что сломается.** Ничего, правка текста.

**Как проверено.** `planApply` в `index.html`: без предупреждений сразу `planSend`, с ними `askConfirm`. Прогон на коммите `1121a3c`: два найденных с логином и паролем, без замечаний, после «Применить план» диалога нет; один `POST /devices` на две строки.

## 2. М-05: после правки производителя кнопка — «Применить план»

**Что нужно.** В `api/ACCEPTANCE.md` вместо «поправить производитель → „Повторить неудачные“ — уходит только она» написать «поправить производитель → „Применить план (1)“ — уходит только она». «Повторить неудачные» оставить в общем абзаце над шагами: кнопка относится к строкам, которым отказал сервер. Такой отказ стоит отдельным шагом проверить, если нужен: например, адрес, занятый после того, как строка попала в план.

**Зачем.** Строка с производителем вне списка не отправляется на сервер, это ошибка самой строки. Она остаётся в состоянии `plan`, отказа не было, поэтому кнопки «Повторить неудачные» на этом шаге нет. По старому тексту шаг не пройти.

**Что сломается.** Ничего, правка текста. Поведение менять не просим: непроверенную строку незачем отправлять, чтобы получить отказ.

**Как проверено.** `planOkRows` и `planFailRows` в `index.html`: первая берёт `state === "plan"` без ошибок строки, вторая только `state === "fail"`. Прогон на коммите `1121a3c`: из трёх строк ушли две, третья осталась в состоянии `plan` с причиной «Такого производителя нет в списке драйверов: выберите из списка». После выбора Bosch ошибок нет, кнопка «Применить план (1)», кнопки «Повторить неудачные» нет.
