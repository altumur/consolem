## Пункт 11. Новые записи в открытом журнале

Живую ленту не делаем: записи, которые сами вставляются сверху, сдвигают список под рукой. Нужна подсказка:
- в потоке событий сервер сообщает, что в журнал добавились записи, без самих записей;
- интерфейс показывает плашку «Есть N новых записей» с действием «Показать», если записи подходят под текущий отбор или их нельзя проверить;
- список меняется только по действию пользователя.

Как назвать событие и что в нём передать (число, уровень, время последней записи), решает mockup. Это отдельная правка со своей версией и уведомлением.
