## Кто что делает

- **Данные вида** mockup делает сам, без уведомления. Это свойства, события и команды существующего вида, которые не меняют `api/openapi.json` (решение 2026-11-16, [ответ о пробелах против Axxon One](2026-11-12-104207Z-mockup-axxon-one-gaps-contract-response.md)).
- **Расширение механизма** mockup тоже может сделать сам: новая проверка сервера, новое поведение, правка `api/openapi.json` без ломающей части. Порядок — скилл `api-contract`, раздел «Правка контракта без владельца». После правки mockup пишет владельцу уведомление `…-done-request.md`.
- **Ломающую правку** делает только владелец.

## 1. Настройки Tag&Track Pro у PTZ-камеры

Принято как данные вида. Свойство `tagTrack` камеры с полями `mode`, `objectTimeSec`, `overviews` — как в запросе. Свойство необязательное: камера без него работает как раньше. Где смотреть: схема вида камеры в `api/fixtures/demo.json`, описание профиля в `api/BACKEND.md`.

Делает mockup, без уведомления.

## 2. Проверки сервера

- **Число точек и точки на одной линии.** Сервер отказывает `422 VALIDATION_FAILED` с `field` `/properties/tagTrack/overviews/<i>/points`. Число точек схема задаёт сама (`minItems`), это данные вида. Проверку «точки на одной линии» схема не выражает: её делает код сервера, поэтому mockup делает её с уведомлением.
- **Обзорная камера не PTZ и не сама камера.** Принято. Сервер смотрит на другой объект, поэтому это новое поведение. Сервер отказывает `422 VALIDATION_FAILED` с `field` `/properties/tagTrack/overviews/<i>/uid`. Делает mockup, с уведомлением владельцу.

## 3. Текущее положение PTZ

Ждёт. Чтение положения PTZ относится к работе оператора с видео. Владелец предлагает вынести видео, архив и управление PTZ в отдельный API (`docs/2026-11-16-kontrakt-i-podsistemy-predlozhenie.md`, п. 7). Сейчас в `PtzMove` есть только скорости осей, положения нет.

## 4. Поворот в точку обзорного кадра

Ждёт, по той же причине, что п. 3. До решения кнопка «Проверить» в прототипе 71 работает на симуляции стенда.

## 5. Погрешность точки

Отклонено. Сервер погрешность не считает. Консоль считает её сама и показывает как подсказку, как сейчас в прототипе 71.

## 6. Лицензии Tag-n-Track

Принято в другой форме. Сейчас `License.kind` в `api/openapi.json` — перечень `cameras`, `acfa`. Владелец сделает `kind` открытой строкой с подписью: тогда бэкенд добавит строку Tag-n-Track без правки контракта. Правка меняет общую схему, поэтому её делает владелец вместе с ответом на [запрос о лицензиях домена](2026-11-06-094022Z-mockup-domain-licenses-request.md).
