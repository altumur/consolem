# Ответ команде w2c: дополнение к запросу об устройствах

Ответ в работе, от 2026-11-01 · на запрос [2026-11-01-094639Z-w2c-devices-update-request.md](2026-11-01-094639Z-w2c-devices-update-request.md) · пункты — по его нумерации.

## П. 1. `ipsrv` создаётся — сделано, `d032cc5`

`ipsrv` — обычный `deviceTypes`, в `foundDeviceTypes` он не входит, `storage` входит. `DELETE` снимает запись устройства, камеры остаются: `parentId: null`, `entity.changed`. Запись без устройства отмечена `Device.derived: true`: `PATCH`, `DELETE`, `folderIds` — `422 NOT_SUPPORTED`. Такой `ipsrv` форма показывает с подписью «выведен из устройства», поля только для чтения, пункта «Удалить» нет. В наборе — «Регистратор склада».

`PATCH` у `ipsrv` с записью: `name`, `enabled`, `lat`, `lon`, `azimuth`, `mac`, `login`, ещё `password`: логин без пароля смысла не имеет. `subtype` выводит сервер, выбор в мастере на него не влияет. Встроенный сервер описаний не имеет и берёт присланное.

## П. 2. Адрес единицы СКУД — сделано, `953777e`

`Device.path` годится, в карточке единицы поле «Адрес». Реле объявлено одновременно в `foundDeviceTypes` и новом `capabilities.unitTypes`: такой вид создаётся только под родителем из СКУД, иначе `422 NOT_SUPPORTED`. Форма реле в СКУД предлагает, вне СКУД — нет.

## П. 3. Папки — сделано, `d032cc5`

`eventsrc`, `acfa` входят в папки. Единицы, реле в СКУД, контроллер, выведенный `ipsrv` и находки сервера — нет: `folderIds`, `folderId`, состав папки — `422 NOT_SUPPORTED`. Форма папку им не предлагает.

## Пп. 4, 5. Поиск устройств — не в этом этапе

Зависят от решения о домене (ADR-0110), делаются с ним.

## П. 6. Варианты `res` на устройство — сделано, `4ac2e90`

`Device.resOptions`, только чтение; нет поля — ввод руками. У прочих потоков свой `DeviceStream.resOptions`. Правильное написание — `1920x1080`, латинская x, схема другое не примет. Значение вне вариантов — `422 VALIDATION_FAILED`, `field: res`. Форма своего не подставляет: нет значения — пусто. `codec` только для чтения, `bitrate` из контракта снят. `BACKEND.md`, «Потоки и разрешение».

## П. 7. `norm` — сделано, `d032cc5`, `57c32b1`

`norm` у `sensor`, `relay` — в `deviceParams`, правится через `PATCH`. `match.value` — начало и конец тревоги относительно `norm`, а не состояние контакта: `active`, `normal`, чтобы не совпадать со словами `norm`. Подписи: «сработал», «вернулся в норму». Набор и шаблоны правил переведены.

## П. 8. `rtspUrl` — сделано, `8e2a25b`

Поле RTSP показывает и пишет `Device.rtspUrl`, собранного из `ip` адреса больше нет, в ручном добавлении поле есть. Создание без `rtspUrl` и без `vendor`, `model` — `422 VALIDATION_FAILED`, `field: rtspUrl`. Правка, которая снимает последний адрес, — то же. Камера под регистратором адрес не требует.

## П. 9. Всё работает — принято

`mic`, `spk`, `eventsrc`, `acfa`, `acfa_*` работают, слово `drv` не нужно. Настройка: запрос о записи, пп. 8–13.
