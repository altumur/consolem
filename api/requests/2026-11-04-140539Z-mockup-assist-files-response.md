## 1. Передать файлы в ходе

Принят второй вариант: отдельная загрузка.

- `POST /files` принимает один файл и отвечает `201 {id, expiresAt}`.
- `AssistTurnRequest` получает необязательное поле `fileIds`, это список `id` загруженных файлов.
- Если `id` неизвестен или чужой, сервер отвечает `422 VALIDATION_FAILED`, `field: fileIds`.

Путь общий. Тот же `POST /files` нужен шаблону экспорта: файлы `export.background` и `export.watermark` из [ответа об опциях домена](2026-11-06-135941Z-mockup-domain-options-fields-response.md), п. 5. Через него же идёт файл ключа лицензии.

**Временный и постоянный файл.** Загруженный файл временный: сервер удаляет его после `expiresAt`. Если объект или опция сослались на `id` файла (фон выгрузки, ключ лицензии), сервер забирает файл себе, и срок перестаёт действовать. Такой файл живёт, пока на него ссылаются. Ход ассистента файл себе не забирает: файл ассистента живёт до `expiresAt`.

Встроенный сервер хранит файл в памяти. Служба ассистента (`?assist=URL`) получает `fileIds`. Если она не умеет читать файлы, она отвечает понятным кодом, как на любое незнакомое поле.

## 2. Пределы и виды файлов

Принято. Пределы лежат в `reference.limits`:
- `fileMaxBytes` — наибольший размер одного файла;
- `filesPerTurnMax` — сколько файлов можно приложить к одному ходу;
- `fileTypes` — допустимые типы MIME.

Интерфейс читает пределы до отправки. Значения для `demo.json` mockup выбирает сам. Условные пределы прототипа (5 файлов, 10 МБ) подходят.

## 3. Ошибки

Принято. Сервер отвечает так:
- `413` — файл больше `fileMaxBytes`;
- `415` — тип файла не входит в `fileTypes`;
- `410` — срок файла (`expiresAt`) вышел, а ход ссылается на него.

Тело ответа — обычный `Problem` с `field`. Если файлов в ходе больше `filesPerTurnMax`, сервер отвечает `422 VALIDATION_FAILED`, `field: fileIds`.

## 4. Секреты в файлах

Решение:
- сервер хранит файл до `expiresAt`, потом удаляет его;
- файл не входит в `context`;
- пароли идут только полем `secrets`, как сейчас;
- содержимое файла проверяет служба ассистента, а не сервер консоли.

Эти четыре правила нужно записать строкой в `api/BACKEND.md`, рядом с описанием ассистента.
