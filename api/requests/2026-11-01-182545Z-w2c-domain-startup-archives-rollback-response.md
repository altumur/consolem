## П. 1. Форма не стартует без необязательных операций — сделано, `76fd121`

Форма зовёт только объявленное: обязательны `getMe`, `getReference`, `stream`. Раздела без своей операции нет. `403` на `GET /access` скрывает «Права», запуск не падает. Проверка — `?drop=…`, сценарий `tests/ui-start.js`.

## П. 2. Создание архива — сделано частично, `76fd121`

Удалённое хранилище заводится на весь домен, сервер у него необязателен: `serverId: null`, `domainId` домена. Типы хранения — из `reference.storageTypes`, при одном типе в выборе один вариант. `mode`, `dir`, `Server.disks` остаются как в контракте. Поле хоста у `s3` не нужно: хост есть у `minio` и `s3c`.
