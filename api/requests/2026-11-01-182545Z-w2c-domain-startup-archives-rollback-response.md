# Ответ команде w2c: запуск, архив, домен, камеры w2c, откат

Ответ в работе, от 2026-11-01 · на запрос [2026-11-01-182545Z-w2c-domain-startup-archives-rollback-request.md](2026-11-01-182545Z-w2c-domain-startup-archives-rollback-request.md) · пункты — по его нумерации. Пункты домена ждут разбора масштаба.

## П. 1. Форма не стартует без необязательных операций — сделано, `76fd121`

Форма зовёт только объявленное: обязательны `getMe`, `getReference`, `stream`. Раздела без своей операции нет. `403` на `GET /access` скрывает «Права», запуск не падает. Любой другой отказ снимка прав, например `5xx` без связи с доменом, запуск тоже не роняет: в разделе «Права» строка «Права сейчас недоступны», при новом заходе запрос повторяется. Проверка — `?drop=…`, сценарий `tests/ui-start.js`.

## П. 2. Создание архива — сделано частично, `76fd121`

Удалённое хранилище заводится на весь домен, сервер у него необязателен: `serverId: null`, `domainId` домена. Типы хранения — из `reference.storageTypes`, при одном типе в выборе один вариант. `mode`, `dir`, `Server.disks` остаются как в контракте. Поле хоста у `s3` не нужно: хост есть у `minio` и `s3c`.

## П. 22. Id одиночной правки — сделано, `5cb5d27`

Id берётся из `GET /operations`. Заголовка нет.

## П. 23. Что откат не возвращает — сделано, `5cb5d27`

Удаление, папки, пароль: шаг `fail NOT_SUPPORTED`, остальные идут. Отмена запрещена целиком — `409 NOT_REVERTIBLE`, `params.reason`: `notLast`, `isRevert`, `expired`, `reverted`, `running`, `empty`. `/devices/update`, `/objects/delete`, `POST /devices`: одна операция на запрос, у `POST /devices` — на строку. Откатить можно только последнюю операцию, откат не откатывается (32142c5). Адрес и объём тома: правки томов в стопку пока не входят, сделается на этапе записи и архива.

## П. 27. Групповые операции — принято

Паузу не объявляем, правка объекта идущей операции — `409 BUSY`. Форма отказывает раньше сервера: перенесена блокировка занятых объектов из прототипа 11, кнопок паузы нет. Откат и повтор считаются операциями.

## П. 28. Помощник — сделано, `5cb5d27`

«Отменить» после «Применить» — `POST /operations/{id}/revert`. `refused` заглушки называет поле и причину.

## П. 4. Код несовместимых детекторов — сделано, `8785295`

`409 BUSY` остаётся, как в нормах, но с причиной: `params: {reason: "incompatible", with: <id детектора>}`. Шаг операции — `fail BUSY` с теми же `params`, для этого у `OperationItem` есть `params`. Форма пишет «несовместим с включённым детектором» и называет его.

## П. 5. Несколько детекторов одного вида — сделано, `8785295`

Форма выдерживает: у каждой записи своя зона и настройки, в наборе такие есть. Цель правила — камера, поэтому событие приходит от любого из них.

## П. 12. Тело аренды PTZ — сделано, `8682dd2`

`{pan, tilt, zoom, focus, ttlSec}`, скорости от -1 до 1, `ttlSec` от 1 до 5, потому что `PTZ_LEASE` в нормах 5 с. В нормах скорости −100…100: это перевод, форма шлёт доли.

## П. 18. Метки серверов — сделано, `5eade8c`

`Server.labels`, `PATCH /servers/{id}`, в карточке сервера. Метка, поставленная на сервер, попадает в `reference.serverLabels`. Новый серверный детектор просит `gpu`; сервера с меткой нет — причина в `faultText`.

## П. 29. Единицы СКУД не только под `acfa` — сделано, `953777e`

Родитель единицы — `acfa`, контроллер, камера или `ipsrv`. Мастер предлагает всех.

## П. 30. Мелкие уточнения — сделано, кроме последнего

MAC камеры, источника, СКУД — только из поиска, `8e2a25b`: без `candidateId` принимается и не хранится, `PATCH` — `422 NOT_SUPPORTED`, в форме только для чтения. `ipsrv` без записи в папки не входит, `d032cc5`. Второй `eventsrc` на порт сервера не запускается, причина в `faultText`, `dfc217e`. При копии по `templateId` не копируются адрес, логин, пароль, имя, записи, папки, детекторы, `8367ba1`. `lpr` в `detectorKind`, `8785295`.

Поля обхода и скана — вместе с ними, на этапе записи и архива.

## П. 8. Показ устройств без сервера — сделано в части показа

Устройство верхнего уровня без `serverId` в раскладке по серверам стоит прямо под доменом, после серверов и их групп, со своими детьми. Отдельной группы нет, слово владельца. Устройства сервера без камер стоят под сервером. Остальное в п. 8 — вариант В, вне этапа.
