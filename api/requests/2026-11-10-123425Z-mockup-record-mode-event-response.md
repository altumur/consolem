- **Ломающую правку** делает только владелец.

## 1. `motion` — «По движению»

Принято с одним отличием от запроса: сервер не создаёт правило.

- Камера получает `recordMode: motion`. Если у камеры нет детектора движения, сервер создаёт его. Детектор встроенный, если камера объявила вид `motion` в `detectorOptions`. Иначе сервер создаёт серверный детектор.
- Если детектор движения у камеры уже есть, сервер второй не создаёт. Повторный `PATCH` с тем же режимом ничего не создаёт.
- Правило записи не нужно. `recordDetectorIds` при `recordMode: motion` уже значит «камера пишет по этим детекторам» (`api/BACKEND.md`, таблица полей камеры). Сервер записывает созданный детектор в `recordDetectorIds`, если поле задано.
- Правило с действием `record` по-прежнему добавляет запись к любому режиму.
- Созданный детектор — обычный объект. Сервер сообщает о нём событием `entity.created`, и консоль показывает его в дереве. Если правка камеры шла шагом операции, откат операции удаляет и этот детектор.
- Режим сменили с `motion` на другой: детектор остаётся, сервер его не удаляет. Администратор удаляет его сам, если детектор больше не нужен.

Кто делает: mockup, с уведомлением владельцу. Это новое поведение сервера. Mockup описывает его в `RecordMode` и в `api/BACKEND.md`.

## 2. Одна операция вместо двух запросов

Не нужно. После п. 1 клиент не создаёт правило, поэтому лишний `POST /rules` уходит.

## 3. Ссылка на объект, созданный той же операцией

Полезно не только здесь: мастера тоже создают объекты и сразу на них ссылаются. Но это общий механизм `/operations`, а не режим записи. Mockup пишет на него отдельный запрос владельцу. Для этого запроса п. 3 не нужен: после п. 1 клиент не ставит номер детектора сам.

## 4. Состояние записи

Поля уже есть: `status.observed.recordState` (`running`, `waiting`, `stopped`) и `status.observed.recordReason` (`api/BACKEND.md`, раздел «Состояние словами» и таблица `status.observed`). Новая причина нужна, только если сервер не смог создать детектор по п. 1. Тогда mockup добавляет её вместе с п. 1.

## 5. Тесты

Тесты mockup пишет вместе с правкой п. 1:
- `PATCH` камеры с `recordMode: motion` без детектора движения создаёт один детектор;
- повторный `PATCH` второй детектор не создаёт;
- правило сервер не создаёт.

## Чего пока нет

- Отдельный запрос о ссылке на объект из той же операции (п. 3).
