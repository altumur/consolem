## 1. Вариант поставки

Принимаем **вариант А**: раздел в консоли, локальные сервер показа и тестовые данные в `demo/`,
загрузка этих файлов только в учебном режиме. Обучение работает без интернета; настоящий API оно не вызывает.

Условия включения:

- показ открывается **отдельной вкладкой**; рабочая вкладка остаётся с настоящей системой и её тревогами;
- до показа человек видит явное предупреждение: в учебной вкладке нет настоящих тревог;
- полоса «Учебные данные» видна весь учебный режим;
- оболочка и файлы остаются за обычной проверкой сессии консоли;
- загрузка через `document.write` проходит проверку CSP во всех браузерах стенда.

«Спецификация VMS» подготовила V/11.1 Н1.4 в ветке `vms/repin-0fbdd12`, коммит
[`6dccdcc86`](https://github.com/altumur/server-vms-course/tree/6dccdcc8612a761fbf5c4fdc60de1504acc68c3c/VMS/11-backend).
Норма теперь задаёт условия включения варианта А. Ближайшая сборка закреплена на consolem `0fbdd12`
с `--without-learn`; условия для учебной сборки ещё нужно выполнить. Ветка передана coord103 на вливание.
При переходе к учебной сборке обновляются `backend.shell.html`, перечень `console.files` и SHA-256 файлов.

По решению о дополнении [103525Z](2026-11-05-103525Z-mockup-learn-section-default-response.md)
ближайший перепин V/11 использует `--without-learn`. Для включения учебной сборки нужны принятие подготовленной нормы,
манифест/SHA-256 учебных файлов и наша проверка настоящей консоли: CSP во всех браузерах стенда и отдельная учебная вкладка.

Где смотреть: `tools/build_webui.py`, `assets/tour.js`, `tests/ui-learn.js`; на стороне w2c — V/11.1 Н1.4.
Сейчас `Tour.play` меняет адрес той же вкладки: условие отдельной вкладки требует правки команды.

## 2. Размер

Принимаем заявленное увеличение сборки примерно на **2 МБ** и обычной загрузки на **63 КБ**.
Учебные файлы загружаются только при `?demo`. Дополнительный численный предел этим ответом не вводим.

Сборщик на прочитанной версии успешно собрал оба варианта: обычная сборка — 18 файлов, 5 659 833 байта;
`--without-learn` — 9 файлов, 3 519 032 байта (суммы `size` из `MANIFEST.json`). Разница — 2 140 801 байт.
В полной сборке есть `tour.js`, `tour-demos.js` и семь файлов `demo/`, в сокращённой их нет.
Это проверка состава сборки; отсутствие запросов за `demo/` при обычной загрузке ещё нужно проверить браузером.

## 3. Загрузка файлов и CSP

Внешние скрипты со своего адреса соответствуют действующей политике оболочки:
`script-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'self'`.
Политику для `document.write` не ослабляем.

Это заключение по коду, а не подтверждение работы во всех браузерах. На итоговой сборке нужно проверить:
все семь файлов `demo/` загружаются до приложения, показ проходит, нарушений CSP и обращений к настоящему
API нет. Сохраняются проверка сессии и проверка SHA-256 статических файлов.

`tools/check_webui.py` и `api/TESTS.md` описывают браузерный стенд только для Chrome.
Проверки остальных браузеров этим инструментом не подтверждены. Проверку во всех браузерах стенда
закрываем отдельным результатом с названиями и версиями; успешный образец консоли её не заменяет.

## 4. Вход

В w2c вход проверяется **до исполнения JavaScript**. По V/11.1 Н1.4:

- оболочка без сессии — `302` на `/?return=/backend/`;
- файлы набора, `HEAD` и API без сессии — `401`.

Поэтому отсутствие запросов к API в учебном режиме не открывает страницу анонимно.
Публичного учебного входа не добавляем. Проверить без сессии обычную и учебную страницы,
а также прямое обращение к файлу `demo/`.

## 5. Настоящие тревоги и роли

Для дежурного принимаем обучение в отдельной вкладке при сохранённой рабочей вкладке.
Учебная вкладка не принимает настоящие события и явно об этом предупреждает; полоса учебного режима остаётся видна.
Тестовые данные не дают оснований для дополнительного запрета по ролям: его не вводим.

Проверка: запуск показа сохраняет рабочую вкладку, её соединение с системой и получение настоящих тревог;
учебная вкладка работает только с тестовыми данными и не меняет настоящие настройки и черновики.
