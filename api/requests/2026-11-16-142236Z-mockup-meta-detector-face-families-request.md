## Что мы делаем

Мы закрываем два пробела против Axxon One (`docs/axxon-one-gaps.html`):

- **C28 «Мета-детектор».** Серверный детектор сравнивает кадр с текстовыми запросами (до трёх) и может сохранять текстовые описания кадров для поиска в архиве.
- **C29 «Несовместимые детекторы».** В системе стоит только один пакет распознавания лиц. Поэтому детекторы лиц TV и лиц VA не работают вместе.

Третий пробел этой работы, CX3 «Стоп-кадр при рисовании зоны», контракта не требует: это только интерфейс.

Сейчас в контракте этого нет. У свойства `analyticsKind` вида `det` есть только значения `tracker` и `neural`. Полей мета-детектора нет. Правила несовместимости серверных видов тоже нет: есть только `detectorOptions[].conflicts` для встроенных детекторов камеры. Прототип 76 (`index_76_meta-stopkadr-semeystva.html`) рисует экраны на заглушке: прототип дописывает значения и поля в схему вида `det` встроенного набора, а значения окна мета-детектора живут в памяти страницы.

## Источники

Axxon One 3.0, документы lexiro 292352 («Configuring the Meta-detector»), 592299 («Functions of the Face detector TV»). Живого сервера Axxon мы не проверяли.

## Что нужно

Имена полей — наше предложение. Владелец контракта может выбрать другие.

1. **Вид мета-детектора.** Значение `meta` в `analyticsKind` вида `det` (действует при `detectorKind: other`, как `tracker` и `neural`), с подписью «Мета-детектор».
2. **Поля мета-детектора.** Необязательные свойства `det`:
   - `metaQueries` — массив строк, не больше 3. Предел длины строки — 200 символов — наше предложение: в документе AO предела нет. Язык запроса не ограничен: по словам пользователя, сервер уже принимает запрос на любом языке. В документе AO 3.0 запросы только на английском — просим записать в описании поля, какой язык принимает сервер.
   - `metaThreshold` — порог совпадения в процентах, 0.05–100, по умолчанию 20.
   - `metaFrames` — сколько кадров подряд кадр должен совпасть с запросом, 10–100, по умолчанию 15.
   - `metaFps` — сколько кадров в секунду проверяет детектор, 0.016–100, по умолчанию 1.
   - `metaSearch` — сохранять описания кадров для поиска по тексту, по умолчанию `false`.
   - `metaSkipSimilar` — не сохранять описание кадра, похожего на предыдущий, по умолчанию `true`.
   - `metaDiff` — насколько кадр должен отличаться от предыдущего, чтобы сервер сохранил описание, 0–100 %, по умолчанию 25.
3. **Без запроса нет событий.** Мета-детектор без единого непустого запроса не создаёт событий. Просим записать это в описании `metaQueries`. Консоль показывает предупреждение «Без запроса детектор не создаст событий».
4. **Детекторы лиц.** Значения `faceTV` и `faceVA` в `analyticsKind` (подписи «Лица TV» и «Лица VA»). По документу AO 592299 в системе можно установить только один пакет из трёх: VA, VL или TV Face Recognition Pack. Если сервер знает детектор лиц VL, просим добавить и его (`faceVL`) в то же правило несовместимости. Тот же документ говорит, что с DetectorPack 3.11.1 детектор лиц TV не поддерживается и его заменил детектор лиц VA. Просим решить, нужен ли `faceTV` в контракте или только для систем со старым DetectorPack.
5. **Несовместимые семейства.** Сервер сообщает, какие серверные виды нельзя использовать вместе в одной системе. Предложение: в описании вида `det` (раздел `kinds`) ключ `x-conflicts` — `{"faceTV": ["faceVA"], "faceVA": ["faceTV"]}`. Сервер отказывает в создании или включении детектора, если в системе включён детектор несовместимого вида: 422 `CONFLICT_KIND`, `field: analyticsKind`, в `params` — uid мешающих детекторов. Консоль заранее показывает причину в мастере и плашку в окне детектора и не даёт включить детектор.
6. **Охват конфликта.** Просим подтвердить, что охват — вся система (все домены), а не сервер или домен. Документ AO говорит о пакете, который стоит один на систему.

## Что сломается

Ничего у тех, кто уже работает по контракту. Значения `analyticsKind` и поля новые и необязательные; клиент показывает незнакомое значение `analyticsKind` как `other`. Отказ из п. 5 — новая проверка, но только для новых значений `faceTV` и `faceVA`, которых раньше не было.
