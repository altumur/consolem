## Сверх запросов

Всё принято:
- отказ при смене вида, `detectorKind` или `serverId` включённого детектора;
- отказ при переносе камеры на другой сервер;
- проверка соседних строк новой камеры в одном `POST /units`;
- таблица в интерфейсе из справочника, а не из константы страницы.

## Что решить владельцу

1. **Охват** — принят, см. п. 3.
2. **`params.with` — массив у всех видов.** Сейчас у встроенных детекторов `with` — строка, у серверных — массив. Владелец сводит оба вида к массиву `uid` следующей версией контракта. Для встроенных это ломающая правка, поэтому её делает владелец, с разделом «Ломающие изменения» в `api/README.md`. Консоль уже принимает оба вида, поэтому в `index.html` ничего не сломается. После правки ветку для строки в консоли можно убрать.

## Чего пока нет

- Правки владельца: `params.with` массивом у встроенных детекторов (п. 2 выше).
- Поиска сервера камеры через архив записи во встроенном сервере. В наборе у каждой камеры есть `serverId`, поэтому сейчас разницы нет.
