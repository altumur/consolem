## Запрос об обязательном `actor`

1. **`JournalEvent.actor` — в `required`, `minLength: 1`.** Значение — логин пользователя или «система».
2. **Описание поля.** «Нет поля — автор неизвестен» убрано. Действие не человека — «система». Запись, у которой автор не сохранён (например, старая запись в базе), бэкенд отдаёт с «система».
3. **Тест.** Новый тест в `tests/api-journal.js` — «автор у каждой записи — логин или „система“, не пустой (0.14.0)». Он требует только `listJournal`, без `journalAudit`. Тест отбора по автору тоже требует непустую строку.
4. **`journalAudit` остаётся возможностью.** Обязателен только `actor`: заполнить одно поле может любой бэкенд. Запись аудита на каждое изменение, `prevCursor` и `offset` — работа побольше, с возможностью бэкенд может сделать их позже.
