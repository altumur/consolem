## 2. Имя компьютера и состояние сервера

Принято: `hostname`, `state` (`active`, `starting`, `stopped`, `noLink`) и `stateText` — свойства вида `server` с `readOnly: true`.

Связь `status.link` не меняется. `state` её уточняет: при `link: offline` консоль по `state` отличает «остановлен» от «нет сети». Если бэкенд `state` не знает, поля нет, и консоль показывает только связь.
