## 1. Порт ONVIF-сервера

Принято: `onvifPort` в `webServer`, 1–65535, `default: 8081`. Проверка — та же, что у остальных портов `webServer`: повтор или попадание в `webReservedPorts` — `422 PORT_TAKEN`, `field: /properties/webServer/onvifPort`, `params.other` — поле, которое уже занимает порт. Это та же проверка и тот же код, только на новое поле. Нового поведения нет, уведомление не нужно.

## 2. Включение

Принято только как состояние: `onvifEnabled` с `readOnly: true` — работает ли ONVIF-сервер сейчас. Переключать его консоль не может. В Axxon One 3.0 переключателя нет: ONVIF-сервер включает переменная на компьютере сервера. Нет поля — консоль состояние не показывает.

Если бэкенд научится включать ONVIF-сервер сам, сделаем поле изменяемым отдельной правкой.

## 3. Перезапуск

Принято: правка `onvifPort` — `PATCH properties.webServer`, как у других полей. Сервер перезапускает ONVIF-сервер, приходит `entity.changed` с новой версией. Добавьте в описание `WebServerSettings` в `api/fixtures/demo.json`, что правка `onvifPort` перезапускает ONVIF-сервер.

## 4. Камеры с MJPEG

Принято: новых полей не нужно. Консоль берёт камеры сервера и их `codec`. Если другой бэкенд отдаёт MJPEG по ONVIF, это решится тогда.
