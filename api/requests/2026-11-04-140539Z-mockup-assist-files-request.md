# Файлы в ходе ассистента

- Дата: 2026-11-04
- Команда: `mockup`
- Коммит контракта: `9c9001d`
- Статус: новый

В прототипе 22 (`index_22_chat-assistenta.html`) оператор прикладывает файлы к просьбе ассистенту: журнал, снимок экрана, список камер. Сейчас прототип показывает только имена файлов в разговоре и говорит, что ассистенту они не ушли.

Что проверили: `AssistTurnRequest` в `api/openapi.json` имеет поля `text`, `context`, `secrets`, `world` и `additionalProperties: false`. В `paths` нет загрузки файлов (`upload`, `file`, `attach`). Файлы для ассистента не описаны в `api/README.md`, `api/BACKEND.md` и в запросе и ответе w2c об ассистенте (`2026-10-30-044153Z-w2c-assist-*`). `assistStub` в `api/server.js` и `assistTurn` в `api/client.js` читают только эти поля. Живого вызова к настоящему бэкенду w2c и к службе `?assist` не было.

## 1. Передать файлы в ходе

**Что нужно.** Способ передать один или несколько файлов с `POST /assist/turns`. Варианты на выбор:

- поле `files` в `AssistTurnRequest`: имя, тип, содержимое в base64;
- отдельная загрузка, например `POST /assist/files` с ответом `{id, expiresAt}`, и поле `fileIds` в ходе.

**Зачем.** Без этого ассистент не видит файл, и кнопка в интерфейсе только показывает намерение.

**Что сломается.** Новое поле необязательное: у тех, кто уже работает по контракту, ничего не ломается. Служба ассистента (`?assist=URL`) должна принять новое поле или отказать понятным кодом.

## 2. Объявить пределы и виды

**Что нужно.** Предел размера, числа файлов и допустимые типы: в возможностях системы или в `reference`.

**Зачем.** Прототип взял условные пределы: 5 файлов, 10 МБ каждый. Интерфейс должен знать настоящие до отправки.

**Что сломается.** Ничего: это новые необязательные данные.

## 3. Ошибки

**Что нужно.** Коды отказа: файл слишком большой, тип не принят, срок загрузки вышел.

**Зачем.** Интерфейс должен назвать причину словами и оставить разговор рабочим.

**Что сломается.** Ничего: это новые коды только для новых полей.

## 4. Секреты в файлах

**Что нужно.** Договорённость: хранит ли бэкенд файл после хода, входит ли файл в `context`, что делать с паролями в содержимом.

**Зачем.** Сейчас договорённость простая: пароли идут только полем `secrets`, в `context` их нет. Файл может её нарушить незаметно для оператора.

**Что сломается.** Ничего: нужно решение и строка в `api/BACKEND.md`.
