# `vms.acs/1` — Единица СКУД с командами

Версия 1.1 · ведёт: mockup · смотрят правку: w2c

Использует: —

Виды эталонного набора: `acfa`, `acfa_sensor`, `acfa_lock`, `acfa_fence`.

## Свойства

| Свойство | Тип | Смысл | С версии |
|---|---|---|---|
| `enabled` | boolean | «Включено» | 1.0 |
| `identifier` | string | Номер устройства в системе («16», «3/1» у канала регистратора) | 1.0 |
| `ip` | string | «IP»: Адрес. У eventsrc — адрес сервера или имя кассы, у драйвера, что подключается сам, — адрес кассы; 0.0.0.0 и :: — 422 VALIDATION_FAILED, field: ip | 1.0 |
| `model` | string | Модель. У единицы СКУД — шаблон из unitOptions: задаётся при создании, правка — 422 NOT_SUPPORTED, field: model | 1.0 |
| `operations` | массив string (только чтение) | У единицы: команды. POST /units/{uid}/actions/{action}, действие unitAction в правиле (только чтение) | 1.0 |
| `path` | string | «Путь»: Папка агента экспорта; адрес единицы СКУД в системе СКУД | 1.0 |
| `properties` | object | Настройки единицы СКУД: ключи — из unitOptions | 1.0 |
| `short` | string | «Короткое имя»: Номер для показа в дереве («3.3.1») | 1.0 |
| `unitOptions` | массив object (только чтение) | У acfa и устройств, под которыми бывают единицы: какие единицы можно завести (только чтение) | 1.0 |
| `vendor` | string | «Производитель» | 1.0 |
