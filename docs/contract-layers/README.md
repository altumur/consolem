## Что лежит в других местах и почему

Слой каждой версии контракта с 0.3.0 по текущую — в [`versions-by-layer.md`](versions-by-layer.md): кому из бэкендов делать версию. Новая версия добавляет туда строку, а `tools/check_api.py` проверяет таблицу.

Открытые запросы по слоям — в [`requests-by-layer.md`](requests-by-layer.md): кто ведёт запрос, какого он слоя и что осталось.

Запросы и ответы между командами остаются в [`api/requests/`](../../api/requests/): их место, имена и статусы задаёт
[`api/requests/README.md`](../../api/requests/README.md). По этой переделке там важны:

- [Плагины psim на 0.2.0](../../api/requests/2026-11-05-110504Z-w2c-psim-plugins-request.md) от w2c и
  [ответ](../../api/requests/2026-11-05-110504Z-w2c-psim-plugins-response.md): адрес страницы на одно открытие, `x-hidden`,
  `statusSchema`, контракт 0.16.0;
- [Универсальная модель объектов](../../api/requests/2026-11-03-065231Z-mockup-generic-model-request.md), п. 11: прежняя договорённость
  о странице плагина, её заменяет документ 2;
- [Базовая форма у встроенных видов](../../api/requests/2026-11-16-191810Z-owner-base-form-builtin-kinds-request.md): «Все параметры»
  у каждого объекта (прототип 77, перенесён в `index.html`).

Описание прежней переделки на универсальную модель —
[`docs/superpowers/specs/2026-11-03-generic-model-design.md`](../superpowers/specs/2026-11-03-generic-model-design.md).
